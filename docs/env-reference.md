## Startup failure behaviour

| Concern            | Behaviour                                            | Gap                                    |
| ------------------ | ---------------------------------------------------- | -------------------------------------- |
| JWT secrets        | API `validateEnv` → process exit                     | none                                   |
| `APP_URL`          | API required in production; web `instrumentation.ts` | none for production                    |
| `API_INTERNAL_URL` | web production `assertProductionApiInternalUrl`      | fixed in Step 7                        |
| Database URLs      | shape-checked at API boot                            | no live connectivity probe in validate |
| SMTP               | always required at API boot (no enable flag)         | bad host fails on first send, not boot |

No `NEXT_PUBLIC_*` secrets — guarded by web `next-public-scan` test.
