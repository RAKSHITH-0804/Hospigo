**If something breaks**

1. Blank dashboard or 502: restart the API; the API refuses to start when the database is behind (it names the migration command).
2. Login says too many tries: wait one minute (limit is about 20 a minute).
3. Wrong or missing data: `npm run dev:reset` again (it drops and rebuilds only the dev database `hospigo`).
4. A print looks wrong: Settings → Print designs → choose another design.
5. Never run the demo on `hospigo_test`; Jest and Newman leave leftovers there.
